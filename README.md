# Foodie — Recipe App

Foodie is an Expo / React Native recipe app that can be opened in Snack Expo or Expo Go.

## Features

- Horizontally scrollable recipe categories, including **My Food** and **Favorites**
- Recipe search, recipe cards, and detailed pages with ingredients, instructions, prep time, servings, calories, and difficulty
- Favorite and unfavorite recipes from either the feed or recipe details
- Add, edit, and delete personal recipes, with photo-library image upload
- Persistent personal recipes and favorites using AsyncStorage

## Run with Expo

Install the dependencies and start Expo:

```sh
npm install
npm start
```

Scan the Expo Go QR code, or use the Snack Expo GitHub import option after this project has been pushed to a **public** GitHub repository. Snack requires internet access to load the sample recipe photos. Recipe content, favorites, and locally added recipes are stored on the device.

## Snack / GitHub submission

Push the contents of this folder (including `App.js`, `package.json`, and `app.json`) to a public GitHub repository. In Snack Expo, choose **Import Git Repository** and enter that repository's URL. The repository URL is not generated until the project is published to a GitHub account.
